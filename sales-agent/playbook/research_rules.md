# Research rules

1. Only return organisations and people you actually found on a web page in this session. Every
   person needs a source_url that names them in that role. If you can't find a named person,
   return the organisation with an empty "people" list rather than guessing.
2. Prefer current information. Skip people whose role you can only find in sources older than two years.
3. Up to three people per organisation, most relevant title first.
4. The hook must be specific to this organisation and checkable: a launch, a regulatory
   disclosure, a hire, a published number, an event they ran. "A leading insurer" is not a hook.
5. The domain is the one their staff email addresses use (often the main website domain).
6. Respect AVOID. When unsure whether an organisation fits, leave it out.
7. Never return personal phone numbers or home addresses.
